# Furcate and Praecise

Furcate is open source, Apache-2.0, and complete for anyone running their own machines. Praecise develops it and stewards it in the open.

Praecise also offers Praecise Furcate, for organisations that run Furcate in production: fleet operation out of the box, edge and cloud deployments, and support. None of it is needed to run Furcate, and nothing in this repository depends on it.

More at https://praecise.com.
